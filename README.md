# Document Graph

Вебінтерфейс для завантаження RDF/Turtle, пошуку документів і трасування зв’язків документа з ключовими словами та правовими актами.

## Запуск

```powershell
python server.py
```

Після запуску відкрийте <http://localhost:8000>.

## API

- `GET /api/graph` — поточний граф.
- `GET /api/documents?q=земельні` — пошук по назві, опису, типу і ключових словах.
- `GET /api/trace/{document_id}` — документ, його ключові слова та всі пов’язані правові акти (`legalActs`).
- `POST /api/upload` — multipart-завантаження `.ttl`, `.rdf` або `.nt`.

Сервер використовує стандартну бібліотеку Python і не потребує встановлення залежностей. За замовчуванням він читає файл `output` у корені проєкту.
